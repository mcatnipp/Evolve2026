EVOLVE DATA CENTER SOLUTIONS - APPROVED LOGO RULES

1. Use only the approved flat-color Evolve logo assets supplied with these rules.
2. Never use the gradient version of the logo.
3. The stylized "e" is always red and must never be changed to black, white, gray, or another color.
4. On light backgrounds, use the red "e" with solid black lettering.
5. On dark backgrounds, use the red "e" with solid white lettering.
6. Do not redraw, approximate, distort, stretch, recolor, add shadows to, or otherwise alter the approved logo.
7. Use the full logo with "DATA CENTER SOLUTIONS" for primary branding. Use the wordmark-only version when the available space is too narrow, such as a footer.
8. If the approved logo asset is unavailable, leave a clean logo-safe area and request the approved file rather than inventing a replacement.
